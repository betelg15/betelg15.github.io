왜 중요한가

주제 한 줄을 세로 영상으로 바꾸는 저장소가 GitHub 스타 14만을 넘으면, 개발자가 볼 질문은 “공짜로 채널이 생기는가”보다 다음입니다.

  • 무료가 저장소 라이선스인가, 스크립트·음성·화면·음악의 청구서인가.
  • “장면 검색”이 문장에 맞는 영상을 생성하는가, 재고 영상을 키워드로 고르는가.
  • 자막이 별도 음성인식인가, TTS가 돌려준 단어 시각인가.
  • 게시 준비가 파일 한 개인가, TikTok·Instagram·YouTube에 올리는 계정 연동인가.
  • pip install에 쓸 이름이 저장소 이름과 같은가.

이 커밋의 답은 파이프라인 코드와 config.example.toml에 있습니다. 기본값은 영어 검색어로 Pexels를 조회하고, 클립 순서는 무작위이며, 배경음악 폴더에 대해 README가 YouTube 출처를 스스로 적습니다.

여섯 단계

cli.py의 단계 순서는 script, terms, audio, subtitle, materials, video입니다. app/services/task.py의 _run_pipeline이 API, CLI, WebUI가 공유하는 순서입니다. 각 단계가 비면 그 단계에서 실패로 끝납니다.

  1. 스크립트. video_script가 비어 있으면 LLM이 쓰고, 사용자가 전문을 넣으면 LLM 스크립트 호출을 건너뜁니다.
  2. 검색어. video_source가 local이 아니면 LLM이 소재 검색어를 만듭니다. match_materials_to_script가 꺼져 있으면 5개, 켜져 있으면 8개입니다.
  3. 음성. 사용자 오디오가 없으면 TTS입니다. CLI가 목소리를 따로 받지 않으면 zh-CN-XiaoxiaoNeural-Female입니다.
  4. 자막. 기본 subtitle_provider는 edge입니다. Edge 실패가 Whisper 다운로드로 넘어가지 않습니다.
  5. 소재. 기본 video_source는 pexels입니다. 음성 길이를 덮을 만큼 받아서 로컬 파일로 둡니다.
  6. 합성. 클립을 이어 combined-N.mp4를 만들고, 내레이션·자막·배경음악을 섞어 final-N.mp4를 만듭니다. 업로드는 이 파일이 생긴 뒤의 별도 단계이고, 기본은 꺼져 있습니다.

stop_at으로 중간 단계에서 멈출 수 있습니다. script와 terms만 만들 때는 FFmpeg를 요구하지 않습니다. 그 다음 단계부터는 FFmpeg가 없으면 태스크가 실패합니다.

스크립트와 검색어는 다른 언어다

app/services/llm.py의 기본 시스템 프롬프트는 영상 주제의 언어로 스크립트를 쓰라고 합니다. 마크다운, 제목, “welcome to this video”, “voiceover” 같은 표시를 넣지 말라고도 합니다. 문단 수는 1에서 10이고, 스키마 기본은 1입니다.

검색어 프롬프트는 다릅니다. 반환은 문자열의 JSON 배열이고, 각 항은 1–3단어이며, 영어만 받는다고 두 번 적습니다. “Chinese is not accepted.” match_materials_to_script가 켜지면 스크립트 순서를 따르는 검색어를 요구합니다. 기본값은 꺼져 있습니다.

레지스트리 LLM_PROVIDER_REGISTRY는 이 커밋에서 44개 id입니다. config.example.toml의 기본 llm_provider는 moonshot이고, moonshot_api_key는 빈 문자열입니다. 빈 모델명과 빈 base URL은 레지스트리 기본을 따릅니다. Moonshot의 기본 모델은 kimi-k3, 기본 엔드포인트 id는 china, 주소는 https://api.moonshot.cn/v1입니다. 같은 스펙에 Global 주소 https://api.moonshot.ai/v1도 있습니다. ollama와 claude_code, openai_codex, kimi_code는 requires_api_key=False입니다. 나머지 다수는 키를 요구합니다. 이 글은 각 업체의 토큰 단가를 조회하지 않았습니다.

기본 화면은 재고 영상 검색이다

VideoParams.video_source의 기본은 "pexels"입니다. Pexels 검색은 이 호출입니다.

params = {"query": search_term, "per_page": 20}
if aspect != VideoAspect.square:
    params["orientation"] = aspect.name
query_url = f"https://api.pexels.com/v1/videos/search?{urlencode(params)}"

orientation에 들어가는 aspect.name은 portrait 또는 landscape입니다. 출력 기본은 VideoAspect.portrait, 해상도 함수는 9:16을 1080×1920, 16:9를 1920×1080, 1:1을 1080×1080으로 바꿉니다. 검색 결과에서는 그 캔버스를 채울 수 있는 렌디션 중 픽셀 수가 가장 작은 파일을 고릅니다. 길이가 minimum_duration보다 짧은 항목은 버립니다.

Pixabay는 https://pixabay.com/api/videos/, Coverr는 https://api.coverr.co/videos입니다. 셋 다 API 키 목록이 있고, 예제 설정은 빈 배열입니다. 키 로테이션은 설정 주석이 적습니다.

같은 파이프라인이 받는 소재 id는 14개입니다. pexels, pixabay, coverr, local, wavespeed, volcengine_seedance, ofox, metaso_minimax, muapi, loomloom, openai_image, codex_image, infistar, jalapeno. CLI가 공개한 선택지는 여기서 loomloom을 뺀 13개입니다. WaveSpeed, Seedance, OFox, Metaso MiniMax, MuAPI, Infistar, Jalapeno는 검색이 아니라 대본 키워드로 클립을 새로 만드는 경로이고, 설정 주석은 요청마다 과금된다고 적습니다. CLI는 그 중 여럿에 --confirm-*-charge가 있어야 materials 또는 video까지 갑니다. openai_image는 키워드마다 이미지를 만들어 줌 클립으로 바꿉니다. local은 사용자가 준 이미지와 영상입니다.

한 편의 기본 이어 붙이기는 VideoConcatMode.random입니다. match_materials_to_script가 켜져 있으면 합성 단계에서 순서를 sequential로 고정합니다. 클립 길이 기본은 5초, 맞추기 기본은 cover(채우고 가운데를 자름)입니다. 이미지 모션 기본은 zoom입니다.

음성, 자막, 음악, 합성

의존성 핀은 edge-tts==7.3.1, moviepy==2.2.1, faster-whisper==1.1.0, imageio-ffmpeg==0.6.0입니다. README는 Edge TTS를 키 없는 무료 음성으로 적고, WebUI의 Azure TTS V1이 그 경로라고 적습니다. CLI 상수 DEFAULT_VOICE_NAME은 zh-CN-XiaoxiaoNeural-Female입니다. parse_voice_name은 끝의 -Female을 떼고, 다른 공급자 접두사가 없으면 azure_tts_v1로 갑니다. 그 함수가 edge_tts.Communicate를 만듭니다. API 모델 VideoParams.voice_name의 기본은 빈 문자열입니다. is_no_voice는 빈 문자열을 무음으로 보지 않습니다. 그래서 README의 CLI 예와, voice_name을 생략한 API 본문은 같은 목소리가 아닙니다.

자막 기본은 edge입니다. TTS가 준 단어 경계로 SRT를 만듭니다. whisper로 바꾸면 로컬 faster-whisper가 오디오를 받아 적고, 문장 모드에서는 그 결과를 스크립트에 맞춰 고칩니다. 기본 모델 크기는 large-v3이고, README는 약 3GB라고 적습니다. large-v3-turbo는 약 1.6GB라는 같은 README의 문장입니다. 장치 기본은 CPU, compute_type 기본은 int8입니다.

배경음악 기본 bgm_type은 random, 볼륨 기본은 0.2입니다. 파일은 resource/songs입니다. 이 커밋의 트리는 output000.mp3부터 output029.mp3까지 29개이고 output026.mp3은 없습니다. 그 디렉터리에 라이선스 파일은 없습니다. 중국어 README의 문장은 “当前项目里面放了一些默认的音乐，来自于 YouTube 视频，如有侵权，请删除。”입니다. 영문 README는 “The current project includes some default music from YouTube videos. If there are copyright issues, please delete them.”입니다. 곡목과 원 영상 URL은 두 README에 없습니다. Sonilo와 ElevenLabs는 별도 유료 음악 공급자이고, 키가 없으면 전체 영상 태스크는 음악 단계에서 미리 실패합니다. 생성이 나중에 실패하면 영상은 음악을 빼고 남기며 경고를 붙입니다.

합성은 video.combine_videos 다음 video.generate_video입니다. 코덱 주석의 기본은 libx264이고, h264_nvenc, h264_amf, h264_qsv, h264_mf, h264_videotoolbox는 선택입니다. 지원되지 않으면 libx264로 돌아간다고 주석이 적습니다. GPU는 README의 최소 요구에 “Not required”입니다. 최소는 CPU 4코어, RAM 4GB입니다.

실행

README의 소스 설치는 Python 3.11 이상을 요구합니다. 예시는 이렇습니다.

git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo
uv python install 3.11
uv sync --frozen
sh webui.sh

첫 실행이 config.example.toml을 config.toml로 복사한다고 README가 적습니다. WebUI 기본 주소는 http://127.0.0.1:8501입니다. API는 저장소 루트에서 uv run python main.py이고, 예제 설정의 listen_port는 8080입니다. 문서 경로는 http://127.0.0.1:8080/docs입니다. app.api_key가 비어 있으면 /api/v1과 /tasks는 인증 없이 열리고, 시작 로그가 그 상태를 경고합니다.

CLI의 가장 짧은 생성 명령은 README에 있습니다.

uv run python cli.py --video-subject "How AI is changing everyday life"

이 명령은 위 기본값을 탑니다. Moonshot 키가 비어 있으면 스크립트 단계에서 멈춥니다. Pexels 키가 비어 있으면 소재 단계에서 멈춥니다. 목소리만은 키 없는 Edge 경로가 CLI 기본입니다. --video-script를 주면 스크립트 LLM을 건너뛰고, --video-terms를 주면 검색어 LLM을 건너뜁니다.

API 생성은 POST /api/v1/videos입니다. 형제 경로는 /api/v1/scripts, /api/v1/terms, /api/v1/audio, /api/v1/subtitle입니다. TaskVideoRequest는 video_count를 1–5, video_clip_duration을 1–15초로 제한합니다. 아래 본문은 그 필드의 이름만 맞춘 예이고, 이 글은 호출하지 않았습니다.

curl -X POST http://127.0.0.1:8080/api/v1/videos \
  -H 'Content-Type: application/json' \
  -d '{"video_subject":"How AI is changing everyday life","video_aspect":"9:16","video_source":"pexels","voice_name":"zh-CN-XiaoxiaoNeural-Female"}'

예제 설정의 최소 칸은 이렇습니다. 키는 빈 값으로 두었습니다.

[app]
llm_provider = "moonshot"
moonshot_api_key = ""
video_source = "pexels"
pexels_api_keys = []
subtitle_provider = "edge"

크로스 포스트는 Upload-Post입니다. 예제에서 upload_post_enabled와 upload_post_auto_upload는 false이고, upload_post_platforms의 기본 배열은 tiktok과 instagram입니다. 주석이 허용하는 값은 tiktok, instagram, youtube입니다. YouTube 공개 범위 기본 문자는 public이고, upload_post_youtube_made_for_kids 기본은 false입니다. 업로드 스레드는 프로세스 안에만 있고, 재시작 후 이어지지 않는다고 주석이 적습니다. 이 글은 Upload-Post의 요금표를 열지 않았습니다.

비즈니스 인사이트

숫자와 정책 문장 옆에는 출처를 붙입니다. 분석/의견이라고 적은 문장만 이 글의 판단입니다. Moonshot, Pexels, ElevenLabs의 2026-11-10 단가표는 받지 않았으므로 편당 원화를 만들지 않습니다.
