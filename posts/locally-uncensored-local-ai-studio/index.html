채팅은 내장 엔진이거나, 이미 떠 있는 서버다

기본 백엔드는 LU Engine입니다. src/api/providers/types.ts의 builtin 프리셋은 http://127.0.0.1:8127/v1, managed: true입니다. 주석은 묶여 있는 llama.cpp llama-server이고, 바깥 설치가 없는 기본값이라고 적습니다. 온보딩 BackendsStep.tsx의 첫 카드 문장은 "LU runs its own engine on your machine. Nothing to install."입니다.

같은 파일이 고를 수 있게 적어 둔 외부 로컬 백엔드는 열두 개입니다. Ollama(11434), LM Studio(1234), Jan(1337), GPT4All(4891), KoboldCpp(5001), llama.cpp(8080), vLLM(8000), LocalAI(8080), text-generation-webui(5000), TabbyAPI(5000), Aphrodite(2242), SGLang(30000). README의 "detects twelve"와 이름이 같습니다. 프리셋 목록에는 그 열두 개 밖에 LiteLLM과 TGI도 있습니다. 클라우드 프리셋으로 같은 파일이 적는 주소는 OpenRouter, Groq, Together, DeepSeek, Mistral, OpenAI, Anthropic, 그리고 사용자가 붙이는 OpenAI 호환 주소입니다. 키 칸이 있습니다.

홈과 README가 모델 개수를 한 숫자로 적지는 않습니다. 홈은 온라인 채팅을 47개와 48개로 같이 적고, 측정은 한 곳에서 44개 중 19개, README는 2026-10-05의 세 라운드 테스트를 포함해 46개 중 19개가 거절 없이 끝까지 답했다고 적습니다. 요금 페이지는 플랜마다 채팅 48, 이미지 15, 영상 6이라고 적습니다. 이 글은 모델 목록을 세어 그 수를 확정하지 않았습니다. 이미지와 영상은 Windows·Linux에서 ComfyUI다

README Create 절은 이미지를 앱이 설치하고, 켜고, 고치고, 업데이트하는 ComfyUI로 그린다고 적습니다. 노드 그래프는 사용자가 만지지 않는다고 적습니다. 클라우드에서만 도는 갈래로 같은 절이 이름을 적는 것은 Upscale과 Erase Object입니다. 홈의 문장도 Enhance와 Erase는 클라우드가 필요하고, 나머지 열 갈래는 자신의 GPU에서도 돈다고 적습니다.

설치는 저장소에서 함수로 열려 있습니다. comfyInstallStore.ts의 runInstall 주석은 "Install ComfyUI, installing Python first when the box has none."입니다. 단계는 checking, python, comfyui, repair, error입니다. README의 첫 실행 문장은, 엔진이 없으면 한 번의 클릭으로 설치하고 ComfyUI도 그렇게 한다는 것입니다. 홍보의 "installs itself"와 문서의 단위는 클릭 한 번입니다. 설치 안내는 Windows 설치 파일 자체를 약 22 MB로 적고, 모델과 ComfyUI와 PyTorch는 그 다음이라고 적습니다. ComfyUI의 기본 위치는 Windows %USERPROFILE%\ComfyUI, Linux ~/ComfyUI입니다.

맥은 이 경로가 아닙니다. README는 맥의 Create가 ComfyUI 없이 맥 자체에서 이미지와 영상을 만들고, ComfyUI·VRAM·LoRA 폴더 설명은 Windows와 Linux라고 적습니다. 다운로드 표의 맥 상태는 베타, Apple Silicon, macOS 14 이상, Intel 제외입니다. 그 표가 가리키는 파일은 LU_3.0.9_aarch64.dmg이고, 문장은 "Mac: 3.0.10 follows shortly, this is the 3.0.9 build."입니다. 홈과 설치 안내도 그 문장입니다. 그런데 v3.0.10 릴리스 자산에는 LU_3.0.10_aarch64.dmg가 있고, 아래 표와 같은 API 응답의 download_count는 21입니다. v3.0.9 dmg은 262입니다. README는 앱이 지금까지 맥 한 대에서 돌았다고 적습니다. Voice는 맥에서 손으로 시험했다고 하고, 컴퓨터 제어는 앱에 있으나 macOS에서 다 시험되지 않았고, Remote Access와 자동 업데이트는 macOS에서 확인되지 않았다고 적습니다.

코딩 에이전트는 대화마다 Ask, Plan, Bypass다

README Code 절은 저장소 지도를 만들고, 요청한 줄만 고치고, 적용 전에 diff를 보여주고, 테스트를 돌린다고 적습니다. 프로젝트 규칙은 .lurules입니다. 모드 이름은 Ask, Plan, Bypass입니다.

태그 v3.0.10의 src/lib/codex-mode.ts는 그 셋을 이렇게 적습니다.

 *   Ask     confirm every arbitrary-exec tool, stage file_write / file_edit
 *   Bypass  local asking off, staging off, the CLOUD shell gate stays
 *   Plan    the read-only chain armed for the whole conversation

같은 파일의 한 줄 설명은 Ask가 "Confirm commands, review edits before they land", Bypass가 "Run without asking. Commands and edits land as they come", Plan이 "Read only. Writes a plan, then waits for approval"입니다. 기본으로 돌아가는 값은 ask입니다. 모드가 어긋나면 더 엄격한 쪽을 고르는 stricterCodexMode가 있습니다. 주석은 화면에 Ask가 보였는데 Bypass로 무인 실행되는 일을 막기 위한 것이라고 적습니다.

Agent 절은 웹 검색과 fetch, 파일, 셸, 코드 실행, 스크린샷, 이미지·영상, 사용자가 붙이는 MCP를 적고, 도구 호출이 사용자가 정한 권한 게이트를 지난다고 적습니다. 3.0.8 노트는 웹 검색이 키 없이 검색 서비스 다섯 곳에 차례로 묻는다고 적습니다. 컴퓨터 제어는 베타이고, 끄개가 기본이며, 터미널과 비밀번호 관리자와 비밀번호 칸은 만지지 않는다고 README가 적습니다. 확인은 Windows에서 돌았고, 맥은 아직 다 시험되지 않았다는 문장입니다.

diff를 먼저 보여주는 경로는 Ask입니다. Bypass는 같은 파일이 "묻지 않고 실행"이라고 적습니다. "권한 게이트가 항상 막는다"와 저장소의 모드 세 개는 다른 문장입니다.

라이선스는 AGPL-3.0-only다

README 마지막은 "AGPL-3.0-only. See LICENSE."입니다. package.json과 Cargo.toml의 문자열도 AGPL-3.0-only입니다. GitHub API의 spdx_id는 AGPL-3.0입니다. LICENSE 첫 줄은 "GNU AFFERO GENERAL PUBLIC LICENSE Version 3, 19 November 2007"입니다. 13절은, 프로그램을 수정한 뒤 그 수정본이 네트워크로 원격 상호작용을 받으면, 그 사용자에게 수정본의 해당 소스를 네트워크로 받을 기회를 내놓아야 한다고 적습니다. 로컬에서 고친 바이너리를 배포하는 의무와, 고친 서버를 네트워크로 여는 의무가 같은 라이선스에 있습니다. lu-labs.ai가 그 의무를 어떻게 지키는지 이 글은 호스팅 소스를 대조하지 않았습니다.

폰은 데스크톱 설치 파일이 아니다

Android 페이지는 LU-3.0.10-Android.apk, 약 31 MB, Android 7.0 이상 arm64, Play 스토어 밖이라고 적습니다. 페이지와 README가 같은 SHA-256을 적습니다. dbd515d81bbc8ab70f21b850424f9f8b57ae88ae24962225beefc4116d139d2f. 이 글은 APK를 받아 해시를 다시 계산하지 않았습니다. 페이지가 적는 기능은 기기 안 모델로의 오프라인 채팅, 문서·메모리·페르소나, 계정으로 여는 LU Cloud의 큰 채팅과 Create와 받아쓰기, 집 Wi-Fi로 PC의 LU에 붙어 PC 모델과 채팅, 자신의 모델 파일입니다. 업데이트는 앱이 스스로 하지 않고, 새 APK를 덮어 설치한다고 적습니다. v3.0.7 APK와 서명이 같아 데이터가 남다고 적습니다. 릴리스 자산에서 APK가 있는 태그는 이 글이 본 71개 중 v3.0.7과 v3.0.10 둘입니다. 같은 응답의 download_count는 12,146과 548입니다.

Cargo.toml의 inproc-engine 주석은, 폰이 데스크톱의 llama-server 사이드카를 띄우지 못하므로 Android와 iOS 빌드에는 프로세스 안 엔진이 항상 들어간다고 적습니다. README 로드맵의 Soon은 "Complete remote access via the mobile app: Chat, Agent, Code and all of Create from your phone, running on your PC"입니다. 그 문장은 아직 나온 기능 목록 밖에 있습니다. iPhone은 README와 iOS 페이지가 App Store 심사 중이라고 적습니다. 홍보 문장에는 iPhone이 없습니다.

비즈니스 인사이트

숫자와 제품 서술은 각 문장 옆의 출처에 붙입니다. 그 밖의 판단은 분석/의견으로 표시합니다.

로컬 카드의 가격은 lu-labs.ai/pricing이 2026-11-06에 보여 준 €0입니다. 그 카드의 한 줄은 "No account needed"입니다. 같은 페이지의 월 요금은 Hosted €19, Hosted Pro €49, Hosted Max €99입니다. 크레딧은 각각 월 900,000, 2,350,000, 5,000,000입니다. 일회권은 €15에 450k, €35에 1.1M, €75에 2.4M, €125에 4.05M, €300에 9.75M이고, 페이지는 만료되지 않는다고 적습니다. Hosted의 일일 채팅 포함은 Flash 11개, Pro와 Max는 12개입니다. 페이지의 면책 한 줄은 "This is not an unlimited-use promise."입니다. 홈이 적은 이미지 단가는 Hosted에서 약 2센트, €15 팩에서 약 3센트이고, 5초 영상은 약 21센트와 약 33센트입니다. 요금 HTML의 Hosted 추정은 빠른 Flux Schnell과 5초 LTX-2를 기준으로 약 0.6센트와 €0.17이라고 적습니다. 두 페이지의 단가 문장은 모델이 다릅니다.

같은 날 claude.com/pricing의 개인 요금은 Pro가 월 $20, 연간은 선불 $200으로 월 $17, Max $100, Ultra $200입니다. cursor.com/pricing의 JSON-LD Offer는 Plus $8, Premium $30, Super $100, Ultra $200, Teams $30입니다. 그 페이지는 월 가격에 서드파티 모델 사용이 포함되지 않고 따로 산다고 적습니다. chatgpt.com/pricing은 플랜 이름으로 Free, Go, Plus, Pro, Business를 보여 줬고, 이 글이 받은 HTML에서는 달러 금액을 뽑지 못했습니다. ChatGPT의 달러 가격은 적지 않습니다.

분석/의견. 목록 가격만 놓으면 LU Hosted €19는 Claude Pro $20과 같은 자릿수이고, Cursor Premium $30보다 숫자로는 아래입니다. 사는 물건이 다릅니다. LU의 €19는 공유 크레딧 90만과 Flash 일일 한도이고, Claude 페이지는 5시간·주간 사용량으로 적습니다. 환율은 이 글이 바꾸지 않았습니다. 로컬 €0의 비용은 요금 페이지 밖에 있습니다. README 표의 18 GB 모델과 6 GB 이상의 VRAM, 설치 안내의 이후 PyTorch·모델 다운로드가 그 비용의 자리입니다.
